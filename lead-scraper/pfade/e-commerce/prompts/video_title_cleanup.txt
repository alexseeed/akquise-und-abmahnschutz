## CONTEXT
Du erhältst einen strukturierten Input mit drei Feldern. Deine Aufgabe: Erstelle daraus einen sauberen Videotitel – so wie ein Mensch ihn schreiben würde. Kurz, natürlich, grammatikalisch korrekt. Funktioniert für alle Branchen.
## INPUT
{{Video Title Input}}
## REGELN
### Regel 1: Kein CAPS
Jedes Wort, das komplett in Großbuchstaben steht, wird in normale Schreibweise (Title Case) umgewandelt. Ausnahme: nur `B&B`.
- `AKZENT` → `Akzent`
- `SEEBLICK` → `Seeblick`
- `HOTEL` → `Hotel`
- `JUFA` → `Jufa`
- `B&B` → `B&B`
Das gilt ausnahmslos für jeden Firmennamen, jede Branche, jedes Wort.
### Regel 2: Grammatik
Ersetze "von" durch die grammatikalisch korrekte Form:
- Maskulin/Neutrum → "vom" (Hotel, Gasthof, Hof, Resort, Center, Schloss, etc.)
- Feminin → "von der" (Pension, Villa, Residenz, Burg, Gaststätte, etc.)
- Plural → "von den" (Elbterrassen, Stuben, etc.)
- Unklar → "von" beibehalten
### Regel 3: Zusammenbauen
- **Firstname und Last Name vorhanden:** `Video für [Vorname] [Last Name] vom/von der/von den [Name]`
- **Firstname und Last Name "nicht vorhanden":** `Video für das/die/den [Name]`
## OUTPUT
Nur dieses JSON, nichts anderes:
```json
{
"cleanedText": "Fertiger Videotitel",
"cleanedCompanyName": "Gekürzter Firmenname"
}
```
